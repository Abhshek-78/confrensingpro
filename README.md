## 📌 Overview

**ConfencingPro** is a **browser-based multilingual video conferencing platform** that uses **Artificial Intelligence** to translate speech in real time.

It leverages:
- 🎥 **WebRTC** for real-time communication  
- 🌐 **MERN Stack** for scalable backend/frontend  
- 🤖 **AI APIs** for speech recognition, translation, and synthesis  

The system removes the need for human translators in meetings, enabling **seamless global communication**.

---

## 🎯 Objective

This project is developed as part of:

> **Experiment-1: Software Requirements Specification (SRS)**  
> Following **IEEE Std 830-1998**

The goal is to:
- Define complete system requirements  
- Build a scalable architecture  
- Ensure performance, security, and usability

## ✨ Features

### 🎥 Core Features
- Real-time video conferencing
- Peer-to-peer communication using WebRTC
- Meeting room creation and joining

### 🌍 AI Features
- Speech-to-Text (STT)
- Real-time language translation
- Text-to-Speech (TTS)
- Bidirectional communication

### 🔐 Security Features
- JWT-based authentication
- End-to-end encryption (DTLS/SRTP)
- Secure HTTPS communication

### ⚡ Performance
- ≤ 2 seconds translation latency
- Supports 1000+ concurrent rooms
- Real-time streaming
